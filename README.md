# ℹ️ Overview:

**Climate Website** is an interactive web application that visualizes Earth and provides climate-related information based on user-selected locations. The project features a dynamic 3D globe interface that allows users to explore geographic coordinates, view temperature data, and better understand global climate patterns.

This project was designed to demonstrate how modern web technologies can create engaging and educational tools for exploring environmental data.

----------------------------------------------------------------------------------------------------------------------------------

## ✨ Key Features

* **Interactive 3D Earth Visualization**
  A rotating globe interface that provides an immersive way to explore locations around the world.

* **Location Tracker**
  Enter any city to locate it and retrieve climate-related data.

* **Coordinate Detection**
  Displays the latitude and longitude of selected locations.

* **Temperature Display**
  Shows temperature data for the searched city.

* **Climate Indicator**
  Includes a global warming percentage indicator to highlight climate trends.

* **Clean Dashboard Layout**
  Simple and intuitive user interface designed for quick access to climate information.

* **History Display**
  How much or how long it's been running for.

## 🌐 API

API only functions with **Your** OpenWeather API key,
in the JS code, scroll to line 191 where you'll see : "YOUR_WEATHER_API_KEY HERE"
Follow the steps in order:
Log onto OpenWeather API > Name > My API Keys > Copy the key or generate a code then paste it here --> "YOUR_WEATHER_API_KEY HERE"
